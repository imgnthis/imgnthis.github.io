Case study: Chip Digger Property Management

The client

A lawn, landscaping, fencing, painting and snow removal company in Glocester and North Scituate, Rhode Island. I built it fully remote, by phone and text.

What I built

  • Eight service cards in a year round layout, so snow removal doesn't vanish in July
  • Drag to compare before and after sliders, plus a project gallery
  • A sticky call bar on phones with tap to call or text
  • An estimate request form
  • Hand written HTML and CSS, hosted on Netlify

What I'd do differently

The estimate form opens the visitor's email app instead of sending right from the page. Next time I'd use a form that submits on the site, because fewer people bail on phones.

Home Internet Speed Monitor

A Python script tests my internet every hour using Windows Task Scheduler, logs the results, and turns them into this chart. The first night showed only about 200 Mbps on a 2 Gbps plan. I traced it to an outdated network card and a test library that under-reports fast connections, so I installed a new card and switched to Ookla's official CLI. Speeds jumped to over 2,000 Mbps, confirmed by pinning every test to one server.
