Home Internet Speed Monitor

A Python script tests my internet every hour using Windows Task Scheduler, logs the results, and turns them into this chart. The first night showed only about 200 Mbps on a 2 Gbps plan. I traced it to an outdated network card and a test library that under-reports fast connections, so I installed a new card and switched to Ookla's official CLI. Speeds jumped to over 2,000 Mbps, confirmed by pinning every test to one server.
